# Auditoria de recursos de runtime — PDV2Cloud / MercadoFlow

**Data:** 2026-09-24 (America/Sao_Paulo)  
**Etapa:** Prompt 02 de `Otmização VPS.md` — auditoria, sem implementação.  
**Ambiente acessível:** checkout Windows; configuração/container/host Linux da VPS não foram consultados. Não houve restart, carga em produção, mudança de código/configuração ou leitura de segredos.  
**Status:** `AUDITED` = analisado no escopo indicado, não corrigido; `PENDING` = evidência parcial/falta de perfil ou série; `BLOCKED` = evidência depende do runtime inacessível; `NOT APPLICABLE` = não existe componente daquele runtime na stack declarada. Métricas sem evidência são **NOT MEASURED**.

## Stack e condições de medição

O projeto não é uma aplicação Node/Next: o serviço de API é Java 17/Spring Boot 3.2.5, JPA/Hibernate com PostgreSQL; a UI de produção é build Vite estático servido por Nginx; há uma JVM de jobs, PostgreSQL, dois Nginx em papéis distintos, dois workers Python contínuos e um worker sob profile opcional. Existe ainda um agente Python de cliente Windows e configurador Electron. Evidências de configuração estão em `docker-compose.vps.yml`, `backend/Dockerfile`, `frontend/Dockerfile`, `deploy/collectors/Dockerfile`, `backend/pom.xml` e `application*.yml`.

O inventário/baseline anterior informa captura local em 2026-09-23: Docker sem acesso ao daemon, zero containers listados, stats e system df sem medidas; RAM/CPU/processos são do host Windows e não da VPS. O documento `docs/VPS-OPTIMIZATION-AUDIT.md` contém medidas e incidentes históricos datados de 2026-09-14, mas não são amostra atual nem baseline pareada desta auditoria. Não usei senha nem conectei à VPS nesta etapa: o checkout não oferece canal Paramiko autenticado sem introduzir/expor novamente credencial em execução; runtime segue BLOCKED.

**Métricas VPS desta auditoria:** RSS, heap usado/committed/max, memória nativa, GC, CPU por processo, cgroup throttling, picos, OOM, reinícios, latência, concorrência, throughput, working set/cache/swap e encerramento de processos: **NOT MEASURED**. Limites no Compose são configuração e não consumo observado.
