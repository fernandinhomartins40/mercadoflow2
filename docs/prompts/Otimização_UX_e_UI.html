Auditoria UI/UX com cobertura verificável

Descobrir tudo, auditar por domínio, consolidar os achados, implementar por fases e verificar o resultado com evidências.

Como usar
Baixe este HTML e abra-o no Chrome, Edge ou Firefox. Clique em “Copiar prompt” e cole na IA que está trabalhando no seu repositório. Execute um prompt por vez. O prompt 9 pode ser repetido para cada fase.

Conclusão com evidência
Inventário → sete auditorias → plano mestre → implementação por fase → auditoria final. DONE exige verificação. BLOCKED e NOT VERIFIED devem trazer o motivo. A cobertura deve informar auditados, aplicáveis, pendentes e não aplicáveis separadamente.
